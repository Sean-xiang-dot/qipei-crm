# 企培 CRM

以可追溯客户事实驱动任务、商机和预测的企业培训销售经营平台。

## 鉴权

系统不使用 ChatGPT 身份作为业务身份。浏览器通过本站同源接口启动企培 CRM MCP 的销售易 OAuth：

1. `POST /api/crm-auth/start` 向企培 MCP 创建登录请求；
2. 用户在销售易页面完成授权；
3. `GET /api/crm-auth/poll` 取得短期 CRM session，并写入本站 HttpOnly Cookie；
4. 后续服务端请求使用 `X-Enterprise-Training-Session-Token` 调用 MCP REST 接口；
5. 客户、商机和写回权限继续由企培 MCP 在服务端校验。

运行时配置见 `.env.example`。

## 本地命令

```bash
npm install

```

## 当前真实数据闭环

- `任务中心`：读取企培 MCP 的本周规则任务候选，保留规则、原因和建议动作。
- `客户`：读取客户生命周期字段，并通过版本锁、幂等键和审计接口完成状态写回。
- `商机`：读取真实潜客、客户、商机和企培阶段字典；支持受控的潜客转化、商机阶段更新以及商机生命周期处置，全部经过权限、事实、幂等和审计校验。
- `销售活动`：读取近 90 天活动；支持粘贴拜访/企微记录，结构化整理后由销售确认并写入销售易活动。
- `经营洞察`：读取客户形态与订单行产品组合、实收贡献、体验里程碑快照及活动质量。

智能整理默认使用本地确定性规则，并在页面明确标记来源。配置 `.env.example` 中的 `AI_PROVIDER=deepseek`、`DEEPSEEK_API_KEY` 和 `DEEPSEEK_BASE_URL` 后可使用 DeepSeek；也保留 `AI_ANALYSIS_*` 通用模型服务适配。无论使用哪种分析方式，都必须由销售确认后写回。

## 页面级数据范围

- 普通销售只读取和操作自己的客户、潜客、商机与任务。
- MCP 从销售易 `user` 对象的字段元数据中发现角色、职能、岗位和职务字段，并返回当前用户的原始身份事实；该能力不绑定具体前端项目。
- CRM 根据这些销售易身份事实动态判断页面权限：主管可以切换“我的/我的团队”，企培事业部负责人还可以切换“企培全量”。不再维护用户 ID、姓名或邮箱白名单。
- 角色或职能暂时无法读取时安全降级为普通销售，只能查看本人数据。
- 团队和企培全量视图中的他人记录保持只读；负责人姓名从销售易用户表实时解析。
- 商机负责人和客户负责人不一致时，会在企培组织边界内补读关联客户基础资料，但不会放宽写权限。

正式环境不会在查询为空或接口失败时展示演示客户、商机或任务。查询成功但没有记录时显示真实空状态；查询失败时显示错误并允许单页重试。
